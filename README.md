# limekana.github.io

The user-level GitHub Pages site for `Limekana`. **Never delete this repository.**

It holds permanent stubs for URLs that shipped app builds link to, so they keep resolving after the studio repos move to the `Limecore-Studio` org. GitHub Pages URLs do not redirect after a repo transfer, but a path on this user site takes over once the project repo that used to serve it has left the account.

Tracking: Limekana/limecore#32, Limekana/limecore#33.
